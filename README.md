# WezTerm 設定

## 概要

WezTerm のカスタム設定。カラースキーム・フォント・背景透過・キーバインドを管理する。

## 設定ファイル

| ファイル | 説明 |
|---|---|
| `wezterm.lua` | メイン設定（外観・テーマ・タブスタイル） |
| `keybinds.lua` | キーバインド定義 |

## 外観設定

| 項目 | 値 |
|---|---|
| カラースキーム | nightfox |
| フォントサイズ | 12.0 |
| 背景透過 | 0.85 |
| 背景ブラー (macOS) | 20 |
| ウィンドウ装飾 | RESIZE のみ（タイトルバーなし） |

## キーバインド一覧

### タブ操作

| キー | 動作 |
|---|---|
| `Ctrl + T` / `Cmd + T` | 新しいタブを開く |
| `Ctrl + W` / `Cmd + W` | 現在のタブを閉じる（確認あり） |
| `Ctrl + Tab` | 次のタブへ移動 |
| `Ctrl + Shift + Tab` | 前のタブへ移動 |
| `Cmd + [` / `Cmd + {` | 前のタブへ移動 |
| `Cmd + ]` / `Cmd + }` | 次のタブへ移動 |
| `Ctrl + PageUp` | 前のタブへ移動 |
| `Ctrl + PageDown` | 次のタブへ移動 |
| `Ctrl + Shift + PageUp` | タブを左に移動 |
| `Ctrl + Shift + PageDown` | タブを右に移動 |
| `Cmd + 1` 〜 `Cmd + 8` | タブ 1〜8 へ直接移動 |
| `Cmd + 9` | 最後のタブへ移動 |

### ペイン操作

| キー | 動作 |
|---|---|
| `Ctrl + Alt + "` / `Ctrl + Shift + Alt + "` | ペインを縦に分割 |
| `Ctrl + Alt + %` / `Ctrl + Shift + Alt + %` | ペインを横に分割 |
| `Ctrl + Shift + ←` | 左のペインへフォーカス移動 |
| `Ctrl + Shift + →` | 右のペインへフォーカス移動 |
| `Ctrl + Shift + ↑` | 上のペインへフォーカス移動 |
| `Ctrl + Shift + ↓` | 下のペインへフォーカス移動 |
| `Ctrl + Shift + Alt + ←` | ペインサイズを左に調整 |
| `Ctrl + Shift + Alt + →` | ペインサイズを右に調整 |
| `Ctrl + Shift + Alt + ↑` | ペインサイズを上に調整 |
| `Ctrl + Shift + Alt + ↓` | ペインサイズを下に調整 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | ペインのズーム状態をトグル |

### ウィンドウ操作

| キー | 動作 |
|---|---|
| `Ctrl + N` / `Cmd + N` | 新しいウィンドウを開く |
| `Ctrl + M` / `Cmd + M` | ウィンドウを最小化 |
| `Ctrl + H` / `Cmd + H` | アプリケーションを隠す |
| `Ctrl + Q` / `Cmd + Q` | アプリケーションを終了 |
| `Alt + Enter` | フルスクリーンのトグル |

### クリップボード・編集

| キー | 動作 |
|---|---|
| `Ctrl + C` / `Cmd + C` | クリップボードにコピー |
| `Ctrl + V` / `Cmd + V` | クリップボードからペースト |
| `Ctrl + U` / `Ctrl + Shift + U` | 文字セレクター（コピーして閉じる） |

### スクロール

| キー | 動作 |
|---|---|
| `Shift + PageUp` | 1ページ上にスクロール |
| `Shift + PageDown` | 1ページ下にスクロール |
| `Ctrl + K` / `Cmd + K` | スクロールバックをクリア |

### フォントサイズ

| キー | 動作 |
|---|---|
| `Ctrl + +` / `Cmd + =` | フォントサイズを拡大 |
| `Ctrl + -` / `Cmd + -` | フォントサイズを縮小 |
| `Ctrl + 0` / `Cmd + 0` | フォントサイズをリセット |

### その他

| キー | 動作 |
|---|---|
| `Ctrl + F` / `Cmd + F` | 検索（選択文字列 or 空） |
| `Ctrl + P` / `Ctrl + Shift + P` | コマンドパレットを開く |
| `Ctrl + R` / `Cmd + R` | 設定をリロード |
| `Ctrl + L` / `Ctrl + Shift + L` | デバッグオーバーレイを表示 |
| `Ctrl + X` / `Ctrl + Shift + X` | コピーモードに入る |
| `Ctrl + Shift + Space` | クイックセレクト |

## コピーモード (`Ctrl + X` で起動)

Vim ライクなキーバインドでターミナル上のテキストを選択・コピーできる。

### 移動

| キー | 動作 |
|---|---|
| `h` / `←` | 左に移動 |
| `j` / `↓` | 下に移動 |
| `k` / `↑` | 上に移動 |
| `l` / `→` | 右に移動 |
| `w` | 次の単語の先頭へ |
| `b` / `Alt + b` / `Alt + ←` | 前の単語の先頭へ |
| `e` | 次の単語の末尾へ |
| `f` | 指定文字へ前方ジャンプ |
| `F` | 指定文字へ後方ジャンプ |
| `t` | 指定文字の手前へ前方ジャンプ |
| `T` | 指定文字の手前へ後方ジャンプ |
| `;` | 直前のジャンプを繰り返す |
| `,` | 直前のジャンプを逆方向に繰り返す |
| `0` / `Home` | 行頭へ移動 |
| `^` / `m + Alt` | 行の最初の非空白文字へ |
| `$` / `End` | 行末へ移動 |
| `g` | スクロールバック先頭へ |
| `G` | スクロールバック末尾へ |
| `H` | ビューポート上部へ |
| `M` | ビューポート中央へ |
| `L` | ビューポート下部へ |
| `Ctrl + U` | 半ページ上へ |
| `Ctrl + D` | 半ページ下へ |
| `Ctrl + B` / `PageUp` | 1ページ上へ |
| `Ctrl + F` / `PageDown` | 1ページ下へ |
| `Enter` | 次の行の先頭へ |

### 選択

| キー | 動作 |
|---|---|
| `v` / `Space` | 文字単位の選択を開始 |
| `V` | 行単位の選択を開始 |
| `Ctrl + V` | ブロック選択を開始 |
| `o` | 選択範囲の反対端へカーソル移動 |
| `O` | 選択範囲の反対端（水平）へ移動 |

### コピー・終了

| キー | 動作 |
|---|---|
| `y` | 選択範囲をコピーしてモード終了 |
| `q` / `Escape` / `Ctrl + C` / `Ctrl + G` | コピーモードを閉じる |

## 検索モード (`Ctrl + F` / `Cmd + F` で起動)

| キー | 動作 |
|---|---|
| `Enter` / `↑` / `Ctrl + P` | 前のマッチへ |
| `↓` / `Ctrl + N` | 次のマッチへ |
| `PageUp` | 前のマッチページへ |
| `PageDown` | 次のマッチページへ |
| `Ctrl + R` | マッチタイプを切り替え |
| `Ctrl + U` | 検索パターンをクリア |
| `Escape` | 検索モードを閉じる |
